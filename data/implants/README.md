# KneeFit3D Implant Library

This directory contains implant and cutting geometries used by
the KneeFit3D research prototype.

## Original TKA 12-Size Library

The `github_original/12_size_range` directory preserves the
complete 12-size baseline library:

- S1-S4
- M1-M4
- L1-L4

Files may include femoral implants, tibial components,
cutting blocks, shells, and associated baseline geometries.

## Persona Femoral Library

The Persona femoral STL files are research-scaled proxy
geometries.

They are NOT official Zimmer Biomet OEM CAD files.

## Persona Tibial Library

The Persona tibial library contains corrected research-scaled
tray geometries covering sizes:

A, B, C, D, E, F, G, H, J.

These components are used for research footprint fitting and
coverage / underhang / overhang analysis.

## Disclaimer

All implant geometries, fitting procedures, cutting workflows,
and rankings in KneeFit3D are intended for research and
prototype development only.

They are not validated for clinical treatment, surgical
navigation, implant ordering, or patient-specific surgical
decision making.
